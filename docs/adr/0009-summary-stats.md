# 0009 统计摘要指标定义

- 状态：已采纳（2026-09）

统计范围：当前低灰阶裁剪设置下、档位亮度 ≤ 500 nits 的有效测量点。

| 指标 | 定义 |
| --- | --- |
| 安全占比 | SVM < 0.4 的单元格面积占比（按单元格在 log 亮度 × 灰阶平面的面积加权） |
| 临界占比 | SVM ≥ 1.0 的单元格面积占比 |
| 全白达标亮度 | G255 截面上，SVM 从此亮度起（向高亮度方向）持续 < 0.4 的最低实测亮度；若始终不达标则为“—” |
| 典型亮度 SVM | 当前灰阶截面在 2 / 10 / 50 / 100 nits 处的插值 SVM（超出测量范围为“—”） |
| 峰值 | 统计范围内最大 SVM 及其（灰阶, 档位亮度） |
| 平均 | 面积加权平均 SVM |

统计页提供卡片视图和可排序表格，可复制为 TSV。
