# 0006 2D 图改为 Canvas 自绘；机型分色、模式分线型、图例在图内右上

- 状态：已采纳（2026-09）

## 背景
Recharts 每帧重算 12 条 SVG 曲线，灰阶扫描动画掉帧；8 种颜色循环导致 12 条线颜色重复；SVG 难以录成视频。

## 决定
- 2D 图用 Canvas 2D 自绘（对数横轴、单调三次插值曲线、0.4/1.0 参考线、十字准线 + 悬停提示）。
- **同一机型同一颜色，同一机型内的不同模式用不同线型**（实线、长虚线、点线、点划线……）。颜色取自经过色盲安全校验的 8 色分类色板，按机型出现顺序固定分配，不循环；可按机型自定义颜色。
- **图例保持在图内右上角**（高亮度区 SVM 普遍较低，不会遮挡曲线），按机型分组，点击可显隐；图例、标题都画在画布里，截图/录屏直接可用。
- 新增亮度截面：固定档位亮度（按 G255 nits 对齐各机型）看 SVM 随灰阶变化。
- 坐标模式保留：标准（亮度 0.01–500 nits，SVM 0–6）、自适应横轴、完全自由。

## 后果
移除 Recharts 依赖。

## 补充（评审修复轮）
- **图例自动避让**：优先放在右上角；若右上角会压住曲线，依次尝试左上、右下、左下，再尝试更紧凑的排版，最后取重叠最少的位置。图例面积不超过绘图区约 24%。一次扫描动画只用一个位置，显隐记录时图例不跳动。
- **相同亮度读数**：实测亮度相同的相邻读数不再取平均，曲线按测量顺序经过每个点（竖直台阶）；自适应/自由坐标按实际绘制的点计算范围。
- **缺口**：记录中缺失或已剔除的单元格造成的缺口用虚线表示、逐渐淡出，绝不画成实线连接。有剔除点的记录在图例、悬停提示和数据表中带 `*` 标记。
- **曲线**：按测量顺序参数化的单调三次曲线，每个点带不透明度，用于缺口和扫描时的淡入淡出。
- **H 键**：`overlays.title` 控制标题与副标题，`overlays.colorbar` 控制图例。

## 补充（修复轮 2）
- **静态截面只画读数**：沿扫描方向的淡入淡出只用于扫描动画。静态截面（未扫描、无过渡）中，不透明度 ≥ 0.5 的点（即悬停提示、数据表、统计会读取的点）画成完全不透明，其余不画；被去掉的点按缺口处理（保留虚线桥接），不再出现半透明的“幽灵”线段。进入/退出扫描的过渡中按点逐步从静态规则过渡到扫描规则，不会跳变。统计的典型亮度 SVM 使用同一条静态曲线。
- **图例字号下限**：图例文字不小于 9 px（参考布局，导出时按比例放大）。放不下时先放宽尺寸上限（两列最宽约 62% 绘图区宽），仍在图内、优先右上；只有绘图区小到连下限字号都放不下时才更小。
- **图例过渡连续**：进入/退出扫描时，静态图例与扫描图例若大小不同，大小和位置随过渡连续变化；一列与两列之间切换时先淡出再淡入，绝不在一帧内突变。
- **演示模式空闲**：指针静止、界面自动隐藏时，十字准线、取值点、悬停提示和图例高亮一并隐藏，指针再动时恢复。
- **切换标签页**：2D 扫描在其标签页隐藏时暂停（与 3D 片头一致），返回后停在原处。
- **演示标题避让**：演示模式下画布内标题的左边缘不小于 `presentSafeLeft`（退出按钮右侧）。

## 补充（修复轮 3：动画中保持坐标模式，自适应实时跟随）
- **动画中保持所选坐标模式**：灰阶扫描（G255→G50）、档位亮度扫描（500→2 nits）以及进入/退出扫描的过渡中，标准坐标固定不动；“自适应横轴”的横轴、“自由坐标”的横轴和纵轴**实时跟随当前帧的数据**（此前扫描期间用整段扫描的范围，固定不变）。自适应横轴的纵轴仍是 SVM 0–6。
- **范围是扫描时间 t 的纯函数**（导出视频按 t 逐帧渲染，见 0003 / 0010）。以 1/60 s 步长对整段扫描求每帧的**按不透明度加权的范围**：每个点按 w = min(1, a / 0.15) 向加权中心收缩，清晰可见的点完全计入，正在淡入/淡出的点部分计入，所以淡入淡出不会让范围跳变。然后平滑三步：① 保持——每条边界取 ±0.5 s 内最极端的值；② 限速——边界移动不超过当前跨度的 100 %/s（前后对称的两遍扫描）；③ ±0.5 s 的零相位升余弦核。三步都只在原始范围之外放宽，所以清晰可见的点（a ≥ 0.15）永远在绘图区内，更淡的点最多被裁掉几帧（曲线始终裁剪在绘图区内）；范围提前一点开始变化、慢一点收回，观感平稳。帧间线性插值。边距规则不变（对数横轴两端各 4 %，自由纵轴 10 % 且不低于 0）。实现见 `src/chart2d/axisTrack.ts`。
- **过渡**同样跟随过渡中各帧的数据：沿过渡进度 p 采样 49 点，保持 / 限速 / 平滑后用线性校正钉住两端——p = 0 时恰为静态截面的范围和刻度，p = 1 时恰为扫描在该时刻的平滑范围。开始 / 结束扫描前先算好范围轨迹和图例位置（全部内置记录约 0.1–0.3 s），不占用过渡动画的时间。截面正好在扫描起点（例如 G255）时，自适应 / 自由坐标也做一次最短 0.35 s 的过渡（静态范围与扫描范围不同，不能一帧切换）。
- **刻度不闪烁、不跳格式**：移动中的坐标轴上每个刻度有自己的不透明度。网格线在边缘内侧淡出，标签在边缘外侧淡出（随刻度滑出绘图区时逐渐消失；不动的边缘上的标签，例如 SVM 0，保持完全可见）；边缘移动越快，淡出区越宽，任何淡入淡出都不短于约 0.15 s。刻度密度（对数轴：只标 10 的整数次幂 / 标 1、2、5 / 全标；线性轴：1-2-5 步长）由整段扫描预先求出的“刻度级别”决定：级别带滞回（跨度在边界附近徘徊时不来回切换），再按时间平滑（±0.5 s），所以切换时两组刻度交叉淡化，跨度稳定时只显示一组。移动中标签按数值本身格式化（“2”“2.5”），同一数值的标签在整段动画中不变；过渡中与静态格式（“2.0”）交叉淡化。对数轴始终是 1、2、5、10… 这类刻度。移动中的网格线和 0.4 / 1.0 参考线不再对齐整像素，位置连续；参考线离开范围时同样淡出。
- **副标题**里的范围数值逐帧更新；移动中每个数值占固定宽度（整段动画中最宽的值）并用等宽数字，副标题其余文字不动。
- **图例**：仍是整段扫描只用一个位置。扫描的放置探针按每个采样时刻自己的坐标轴映射到屏幕，过渡两端各用自己的坐标轴，所以避让与实际画面一致、过渡中不跳。
- **静态行为不变**：静态截面（未扫描、无过渡）和标准坐标的所有帧与之前完全相同（单元测试与旧实现逐项对比）。单元测试见 `src/chart2d/axes.test.ts`：范围是 t 的纯函数；全部内置记录及小子集（仅小米 18 Pro Max、仅 iPhone 18 Pro Max、三条记录）以 60 fps 检查每帧变化 ≤ 跨度 2.5 % 且无单帧突跳；刻度不透明度每帧变化 ≤ 0.2、标签文字不变；过渡两端精确。
