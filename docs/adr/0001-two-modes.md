# 0001 分析模式 + 演示模式并重

- 状态：已采纳（2026-09）

## 背景
工具既用于自己/同行查数据，也用于做评测视频和图文（原代码里的“隐藏 UI”、大标题、Neon 配色、开场动画都说明了这一点）。两类需求混在一个顶栏里，导致控件拥挤、画面不干净。

## 决定
- **分析模式**（默认）：左侧记录列表，中间视图，右侧参数面板；顶栏只保留主标签页、演示、导出、语言、设置。
- **演示模式**：全屏，隐藏所有面板；画面内只保留标题、图例/色标、坐标轴；时间轴在鼠标移动时出现、静止后自动隐藏。快捷键：空格播放/暂停、←/→ 拖动、R 重播、H 隐藏标注、Esc 退出。
- 画面内需要出现在截图/视频里的元素（标题、图例、色标、坐标轴）都画在画布里，不依赖 DOM 叠加层，保证导出所见即所得。

## 后果
视图组件要同时支持“交互尺寸”和“导出尺寸”两种渲染；见 0010。

## 补充（2026-09）：演示模式的覆盖层与 H

- **退出按钮**固定在窗口左上角（16–48 px，指针移动时出现）。Shell 按舞台位置发布 `presentSafeLeft`（CSS px）：舞台顶到窗口顶、
  左侧没有足够黑边时约为 56，9:16 / 1:1 等左右有黑边的画幅为 0。视图左上角的标题 / 页头从 x ≥ `presentSafeLeft` 开始。
- **按键提示**（进入演示后约 2.5 s）不压任何标题、坐标轴标签、图例或数据（`src/shell/presentLayout.ts`）：左右有黑边时放在右侧黑边内
  （与退出按钮同高，黑边窄时在“按键 动作”之间换行）；只有下方黑边时放在下方黑边中；舞台铺满屏幕时放在舞台顶部标题带的右端——
  三个视图都让出这一带：3D 标题左对齐且画面留有顶部边距，2D 标题居中（提示与中线保持 ≥ 170 px），统计页头右侧只有演示时隐藏的控件。
- **H**：3D / 2D 隐藏 / 恢复画面内标题与图例、色标。统计页没有画面内标题：演示模式中 H 隐藏 / 恢复统计页头（跟随 `overlays.title`）；
  工作台里统计页头承载控件、始终显示，H 不改任何开关（不会悄悄关掉 3D / 2D 的标题），只提示。
- **通知**（toast）底部居中，但始终在标有 `data-toast-avoid` 的底部控件之上：时间轴（及其上方约 64 px 的坐标轴标签）、2D 工作台的
  传输条（及其上方的 x 轴刻度与标题）。这样抬高时一次只显示最新的一条（其余排在后面），不会向上叠进画面。演示模式不显示通知。
