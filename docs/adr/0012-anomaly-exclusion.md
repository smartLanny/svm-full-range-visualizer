# 0012 明显异常值的检测与剔除

- 状态：已采纳（2026-09）；“剔除”的做法（把异常点从记录里移除）已被下文的**补充：降噪（2026-09-30）**取代——记录永远保留原始测量，异常处理改为显示时的“降噪”选项。

## 背景
小米 18 Pro Max 两条记录里有大量负亮度读数、复制错行的亮度、重复的整列和孤立的 SVM 尖峰。它们会在热力图上形成大块深红、让 2D 截面曲线出现折角，也会拉偏统计结果。项目原则是“不修改原始测量”，但明显无效的读数继续展示只会误导。

## 决定
异常检测写成可复用的规则（`src/data/anomalies.ts`，有单元测试），按顺序判定，一个单元格只记第一个命中的原因：

1. **低于噪声底**（belowNoise）：实测亮度 ≤ 黑场噪声上限，即 G ≤ 2 两行读数的“均值 + 3σ”（不低于 0）。这样的读数和全黑分不开，由它算出的 SVM 没有意义。没有黑场行的记录只剔除 ≤ 0 nits 的读数。
2. **重复列 / 重复行**（duplicateColumn / duplicateRow）：相邻两列（行）每个单元格都完全相同，属于源表复制错误；剔除较暗的那一列（行）。
3. **陈旧读数 / 错行亮度**（nitsShift）：用中位数平滑（median polish）拟合整表的亮度规律 log(nits) ≈ 灰阶效应 + 档位效应。实测亮度偏离拟合值 20% 以上、且与相邻格读数相差不到 2.5%（典型的“画面还没切换就记了读数”或粘贴错行），或偏离 35% 以上，即判为异常。只判定明显高于噪声底的单元格。
4. **SVM 尖峰**（svmSpike）：SVM 是周围有效单元格中位数的 3 倍以上（或 1/3 以下），且绝对差 > 1.0。

剔除的做法：被剔除的单元格在网格中设为缺失（null），原始值和原因完整保存在记录 JSON 的 `excluded` 字段里，`restoreExcluded()` 可以原样还原；没有任何有效单元格的行或列会从网格视图中去掉。噪声底始终按原始读数计算，所以对已清洗的数据重复检测不会再剔除新的点。

## 范围
目前只对用户确认的小米 18 Pro Max 两条记录执行了剔除。同一套规则在其他内置记录中也发现了陈旧读数（小米 17 Ultra 各 18 处、华为 Mate 80 RS 标准 13 处等），是否剔除由数据提供者确认后再执行。

## 后果
18 Pro Max 在低亮度、低灰阶区域会出现空缺（热力图斜纹），这表示“该仪器在此处测不准”，而不是“频闪为 0”。与其他记录的差值图只在双方都有效的区域计算。

## 补充：降噪（2026-09-30）

### 背景
按上面的做法，剔除是**破坏性**的：被剔除的点从网格里删掉（原始值挪到 `excluded`），而且只对部分记录执行（小米 18 Pro Max、iPhone 18 Pro Max 两组导入时剔除，其余 12 条原样），各记录处理标准不统一。复核还发现旧规则有三处不对：

1. **黑场噪声被高估**：旧的噪声底取 G ≤ 2 两行**全部**读数的“均值 + 3σ”，但亮档位的 G2 带有真实亮度（iPhone 100% 档 G2 约 0.018 nits；华为 Mate 80 RS 标准 80% 档的两个读数把噪声底抬到 0.066 nits），于是约 99 个可信的低亮度 PWM 读数被误删。
2. **“亮度读数未更新”的格子 SVM 其实是好的**：例如 iPhone 18 Pro Max 标准 G51 / 90%，亮度 27.38 nits 与 G60 的 27.36 相同（画面切换后亮度没刷新），但 SVM 0.656 与平滑脉冲同格 0.653 一致——整格删掉等于丢掉真实的 SVM。
3. **SVM 尖峰规则要求至少 3 个有效邻格**，漏掉了角上的尖峰（小米 17 Ultra DC G21 / 0%：0.01 nits 下 SVM 22.73）。另外档位亮度取自 G255 格，G255 读数坏了整列都会错位（华为 Mate 70 Air 低频闪 60Hz 27% 档：28.3 nits，同机其他模式约 36 nits）。

### 决定
- **记录永远保存原始测量。** 内置文件和本地保存里若带 `excluded`（旧版剔除的点），加载时放回网格（`rawDataset`）。导入不再删除任何点。
- **降噪是显示时的一个处理步骤**：`processRecord(record, { denoise })`（`src/data/denoise.ts`，纯函数，按记录 + 选项缓存），对每条记录（内置或导入）完全一样地执行。3D、2D、统计和导出都显示它的结果。
- **设置“降噪”，默认开**（持久保存；旧存档没有这一项时按默认开）。关闭时一切按原始值显示（杂讯可见），只有画不出来的值（对数轴上 ≤ 0 nits）不画。
- **真实（可信）的测量值绝不改动**：没有被标记的格子就是原始读数本身（对全部内置记录做了属性测试）。

#### 检测（按灰阶 / 亮度档位顺序找相邻格）
1. **黑场噪声**（仪器看全黑时的读数水平）：只用真正暗的读数——G ≤ 2 行里、档位亮度 ≤ 100 nits 的列（这些位置的真实亮度远低于一个读数步长）。取中位数，加上“离中位数最近的 90% 读数”相对中位数的均方根的 3 倍，不低于 0。读数量化成全 0 时结果就是 0，**不额外加一个读数步长**。没有 G ≤ 2 行的记录只把 ≤ 0 nits 当作黑场。亮度不高于黑场噪声的格子和全黑分不开，其 SVM 没有意义。**低于 1 nit 的读数不会因此被整体去掉。**
2. **重复行 / 重复列**：相邻两行（列）每格完全相同，是源表复制错误；较暗的那一行（列）不是它自己位置的测量。
3. **亮度读数不可靠**：整表亮度规律为 log(nits) ≈ 灰阶效应 + 档位效应（中位数平滑拟合，只用明显高于黑场的格子，去掉已标记的格子反复拟合）。
   - **亮度读数疑似未更新**：偏离规律 > 20%、偏离本列上下格插值 > 15%，并且与某个相邻格读数相差 < 2.5%（画面切换后亮度没有刷新）。**SVM 是重新测的，保留。**
   - **亮度偏离整表规律**：偏离规律 > 35%，并且偏离本列插值 > 35% 或在本列里顺序颠倒（比更亮一级灰阶还亮）。整列平滑、只是不符合“可分离”规律的区域（例如某档位低灰阶整体偏亮）不算。SVM 保留。
   - **读数疑似未更新（亮度和 SVM 都没刷新）**：上面这种格子，若 SVM 也与相邻格相差 < 1%（亮度相差 < 15%），而本列上下的可信格子说明 SVM 应当相差 > 10%，则整条读数是重复的，SVM 也不可信（连续的一串一并识别）。例如华为 Mate 80 RS 标准 27% 档 G83–G60：5.25 / 5.26 / 5.27 nits、SVM 1.262 / 1.26 / 1.257。
   - **档位亮度**取自该列 G255 格；该格亮度不可靠时，按整表亮度规律（该列其他可信灰阶）重新估算。
4. **SVM 尖峰**：与周围至少 **2 个**可信邻格（含对角）的中位数相差 3 倍以上，并且绝对差 > 1.0 或相差 10 倍以上。

#### 处理（降噪开）
- **黑场、SVM 尖峰、整条读数未更新**的格子：只有当两侧都有**高度可信**的实测格子（SVM 可用、亮度明显高于黑场噪声）、且中间空缺不超过 2 格时，才**插值补全**——先沿本列灰阶，否则沿本行档位亮度；SVM 按对数插值、亮度按几何插值，**绝不外推**。否则显示为**无有效数据**（斜纹）。尖峰格保留自己的亮度（实测或估算）。
- **重复行 / 列**：无有效数据。
- **只有亮度不可靠**的格子：保留实测 SVM，亮度换成估算值（本列上下格插值，否则整表规律），用于需要单格亮度的地方（2D 灰阶截面的横坐标、提示中标“估算”）。
- 每个被处理的格子都带说明（`CellNote`）：做了什么（插值补全 / 无有效数据 / 亮度为估算值）、原始读数、用白话写的原因和数字、插值来源格。
- 低灰阶裁剪（默认隐藏 G<15，见 0004）不变；关闭裁剪时低灰阶行经过同一套处理。

### 后果
- 所有记录按同一标准处理，处理与否由一个开关控制，随时可以对照原始值。
- 统计在降噪后的数据上计算；覆盖率把实测格和插值格都算作有效，并报告“插值 N 格、无有效数据 M 格”，不再有“已剔除”。
- 旧的 `excluded` 字段仍可读入（加载时还原），不再写出；`src/data/anomalies.ts` 的破坏性剔除不再被界面使用，应用只用其中的 `restoreExcluded()`。

### 界面上的呈现（2026-09-30）
- **一个开关**：设置 `denoise`（默认开，持久保存）在设置弹窗、3D / 统计参数面板的“数据范围”和 2D 参数面板的“显示”里，说明只有一句白话。3D（所有布局、差值图、开场动画）、2D（截面、扫描、数据表）、统计（卡片、表格、缩略图）和所有导出都用同一个显示记录（`displayOf()` / `useDisplayRecords()`），所以开关对它们一致。关闭时一切按原始读数显示，只有画不出来的值（对数轴上 ≤ 0 nits）不画。
- **提示说清楚做了什么**：3D、2D 十字线提示、统计缩略图和 2D 数据表中，被处理的格子都给出“插值补全 / 无有效数据 / 亮度为估算值”、白话原因（带数字）、插值来源或亮度估算方式，以及原始读数；亮度为估算值时，实测亮度后标“估算”，重估的档位亮度同样标注。界面不用“陈旧读数”“噪声底”“剔除”等术语。
- **插值补全看得出、但不抢眼**：俯视图中在采样点画一个小空心圆（地形压平时淡入，显示数值表时让开，格子太小时不画；立体视角不画）；2D 静态截面上画同样的空心点（扫描动画中不画，视频保持干净）；数据表中为斜体虚线下划线。无有效数据沿用中性斜纹，2D 曲线断开并以点线示意，从不连成实线。
- **计数代替“已剔除”**：记录面板显示“降噪 N 格”（悬停列出插值补全 / 无有效数据 / 亮度为估算值的格数、发现的问题和有效格数）；统计卡片 / 表格显示统计范围内的“降噪 N 格”（悬停：“降噪（统计范围内）：插值补全 a 格，无有效数据 b 格……”），覆盖率把实测格和插值格都算作有效，TSV 中给出三列计数。2D 图例不再有“*”标记（所有记录都经过同一处理），图例行的悬停提示给出该记录的处理情况。这些徽标是中性的，不是警告色。
- **导入**：不再有“剔除明显异常值”勾选框。导入的始终是原始读数，预览列出降噪将处理的格子（按处理方式和问题类型），并说明原始读数会保留、降噪只影响显示。
- **低灰阶裁剪关闭时**：G<15 行经过同一套处理，接近全黑的格显示为中性斜纹，图面不再被 0 nits 附近的杂讯（SVM 几十到几百、亮度 ≤ 0）主导；仍高于黑场噪声的读数照常显示（颜色在色标上限饱和、高度在高度上限截断，与其他区域一致）。默认仍然裁剪 G<15（ADR 0004）。
- **扫描动画**：2D 扫描的“不跳变”检查改为在显示记录（降噪开）上进行；降噪关时只检查点不会突然出现 / 消失 / 闪烁——原始杂讯（如 −0.05 nits 处 SVM 62.8）本身就是陡峭的，允许它快速移动。
