# 0003 动画由时间轴驱动，保留原分镜

- 状态：已采纳（2026-09）

## 背景
旧开场动画在渲染循环里每帧调用多个 React `setState`，整棵 3D 场景（含几十个文字对象）每帧重渲染；镜头缩放每帧被强制设置，同时 OrbitControls 阻尼还在起作用，两者打架；8.5 秒和结束时各有一次镜头硬切；柱子按灰阶组严格串行线性生长，看起来一顿一顿。

## 决定
- 保留原分镜：G255 柱子长出 → 镜头转向俯视、其余灰阶自上而下依次长出 → 柱子压平成数值表 → 渐变为热力图 + 等高线。
- 画面是时间 t 的**纯函数** `evaluate(t)`：渲染循环只读时间、直接改 uniform / 实例矩阵 / 相机，不触发 React 渲染。
- 统一缓动：生长用 easeOutCubic，灰阶组之间有重叠窗口形成连续“波浪”；镜头用一条连续路径（无硬切），终点正好落在俯视正交画面。
- 时间轴：播放/暂停、重播、拖动进度（带章节标记）、0.5×/1×/1.5×/2× 调速、循环。动画期间禁用鼠标旋转，拖动时间轴即可逐帧检查。
- 2D 灰阶扫描同理：曲线是灰阶的连续函数，端点不跳变。

## 后果
导出视频时可以按帧逐一求值渲染，得到与机器性能无关的平滑结果（见 0010）。

## 补充（评审修复轮）
- **2D 扫描不跳变**：扫描中某条记录在相邻灰阶行/档位列缺数据时，点保持最后一个测量值，并在相邻区间内淡出（至少约 8 帧），短缺口用降低不透明度的插值跨过；超出记录测量范围的档位亮度按边缘列保持并淡出。单元测试逐条内置记录以 60 fps 检查：点只在不透明度 ≤ 0.1 时出现或消失，每帧不透明度变化 ≤ 0.2。
- **进入/退出扫描**：从当前截面值平滑过渡（0.35–1.2 s）到扫描起点，关闭时平滑回到原值；时间轴区域始终占位，画布高度不变。这个过渡只属于界面，导出的视频从扫描起点开始。
- **导出视频的时长和起点**由各视图的 `animation()` 决定；3D 开场动画在并排/差值布局下按记录 A 单独渲染（见 0010）。
- **3D 开场动画的缓动（修复轮）**：原“easeOutCubic + 灰阶组波浪”在逐帧差分中仍有周期性尖峰（每组开始时整行同时起跳）。现在每根柱子各自用 smootherstep 生长（起点速度为 0，1.4 s 窗口互相重叠），起始时刻沿对角线均匀错开，没有“整行同时开始”；柱子出现时占地面积 60%→100%、颜色从底板色渐变到色标（前 0.2 s），不再有可见性开关。单元测试保证每帧的生长量在局部中位数 ±30% 内。
- **镜头路径**：摇臂取景由 49 个精确取景点做最小二乘 5 次多项式拟合（精确取景在限位角点切换处有折角），并抬高到永不比精确取景更紧；各段 smootherstep 缓动并互相重叠，速度连续（C2）。收窄到正交（7.0–9.0 s）与压平（7.3–8.9 s）错开进行，底板边缘的坐标标签在收窄期间淡出、压平后在俯视位置淡入。
- **时长与章节**：开场动画总长 13.2 s，章节 0 / 1.9 / 7.0 / 9.9 / 11.3 s；时间轴章节刻度可点击跳转，`[` / `]` 切换章节（全局快捷键）。
- **动画中改变结构**：开场动画进行中切换布局、呈现、视角、记录 A、低灰阶裁剪、亮度上限或高度上限时，先结束开场动画（交叉淡化），再应用改动。
- **暂停时导出 PNG** 得到的是时间轴当前时刻的画面（与离线渲染 `renderFrame(t)` 逐像素一致）。
- **界面里开始 / 重播开场动画**不再硬切到空底板：从屏幕上当前画面用 0.8 s smoothstep 溶解到 t = 0 的画面，标题和色标在界面里保持显示（它们本来就在屏幕上）；导出的视频仍从 t = 0 开始、标题从黑场淡入，不受影响。播放中往回跳超过 0.5 s（重播、循环）同样溶解；暂停拖动仍是直接跳转。
- **交叉淡化的快照**直接从画布复制上一帧的像素（同样的多重采样、混合和色彩编码），淡化第一帧与上一帧逐像素相同。
- **演示模式空闲**（光标隐藏）时清除 3D 悬停提示和单元格描边，鼠标再动时恢复。
- 开场动画进行中导出的 PNG 按画面命名：`<A>_开场动画_5.0s`。
